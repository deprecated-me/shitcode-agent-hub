01

本週焦點 Takeaways

跨本週 8 份日報彙整，反覆出現的專案、主題與 agent skill 走向。

1

記憶層成為 Agent 的新標配基建

codebase-memory-mcp 整週穩居 Top 2（自 06-18 起連霸），06-27 單日再爆 +94.6%；topoteretes/cognee（知識圖譜引擎）06-30 首進 Top 5。「持久記憶 + 知識圖譜」已從副題材升格為主賽道。

2

垂直應用 Agent 開始各據山頭

影片（OpenMontage）、金融（daily_stock_analysis）、投資研究（ai-berkshire）、行銷觸達（Agent-Reach）同框 Top 5。Agent 已從「通用工具」走向「產業垂直規模化競爭」。

3

Skills 方法論熱潮退燒，接力棒交給「規範」

六月中霸榜的 last30days-skill、addyosmani/agent-skills、pm-skills、SkillSpector 本週集體退潮；接手的是 google-labs-code/design.md——為編碼 Agent 定義視覺識別規範，代表社群從「教 Agent 技能」轉向「約束 Agent 產出」。

4

Context／Token 效率成為明確採購點

新進的 OmniRoute 以單端點串接 231+ 供應商、RTK+Caveman 疊加壓縮省下 15–95% tokens；搭配記憶層降低重複脈絡，反映開發者對「多模型路由 + 成本優化」的真實付費意願。

5

安全、品質與隱私回潮

no-mistakes（git push 安全）、Anthropic-Cybersecurity-Skills（817 個資安技能）、去識別化通訊 simplex-chat 週末重返 Top 5。在 Agent 大規模自動化下，「防呆與可控」的需求同步升溫。
