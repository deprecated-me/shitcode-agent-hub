## 2) 主題趨勢

1. **「Build Your Own X」教育文典暴發，529K 巨型 repo 首度入榜**：[codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) 空降 #3，4,863 ⭐/wk，在歷史全檔（約 90 天）中首次錄得紀錄。經典程式教育 repo 突然爆發 2026 上半年最高單週星數，暗示開發者在 AI 寫程式的反向浪潮中「重新學習電腦底子」的需求。這跟 Rust 底層工具鏈的復甦（[openinterpreter/openinterpreter](https://github.com/openinterpreter/openinterpreter)、[earendil-works/pi](https://github.com/earendil-works/pi)）形成呼應：Agent 越是萬能，工程師越需要「搞懂底層」的對沖投資。

2. **Agent 穩定性與治理需求上升——安全 + 教育雙軌並進**：[Dicklesworthstone/destructive_command_guard](https://github.com/Dicklesworthstone/destructive_command_guard)（Rust，1,410 ⭐/wk，歷史首次進榜）專封危險 git/shell 指令，為 Agent 安全治理第一線工具；[anthropics/cwc-workshops](https://github.com/anthropics/cwc-workshops)（TypeScript，385 ⭐/wk，首次進榜）是 Anthropic 官方培訓資料。Agent 已從「能跑」進化到「要安全地跑、要教會人怎麼跑」。

3. **Agent × 多媒體（影片 + 設計）持續分化領跑 vs. 交易軟腳**：[OpenCut-app/OpenCut](https://github.com/OpenCut-app/OpenCut) 連跌 2 日但仍 76.4K 總 ⭐ 穩坐 #1；[Nutlope/hallmark](https://github.com/Nutlope/hallmark) 盤整中連續 7 日；[ibelick/ui-skills](https://github.com/ibelick/ui-skills) 從 1,669 → 1,925 ⭐/wk ▲ +15.3%；[iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI) 連 11 日在榜。但 [HKUDS/Vibe-Trading](https://github.com/HKUDS/Vibe-Trading) 跌幅擴大（▼ -16.1%），交易 Agent 的「新鮮感」退潮速度比預期快。

4. **Rust × Coding Agent 下半場：openinterpreter 全面反超 openai/codex**：[openinterpreter/openinterpreter](https://github.com/openinterpreter/openinterpreter) 2,644 ⭐/wk（▲ +5.8%）持續壓制 [openai/codex](https://github.com/openai/codex)（Rust，今日未顯示具體數據但仍在榜）的「鏡像競爭」中，開源派已連續 2 日維持 stars/wk 領先。閉源 vs. open model 的 agent 戰爭中，開發者用星數投票——且開源持續獲勝。

## 3) 值得追蹤專案

1. **[codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x)** — Markdown，4,863 ⭐/wk，529K 總 ⭐，**歷史全檔 0 記錄首次進榜**。程式教育最古老的 repo 之一，在 AI  Coding Agent 百家爭鳴的年代突然爆發，不是偶然——當 AI 能幫你寫程式，你更需要「從底層搞懂程式怎麼運作」。這可能是 2026 下半年「逆 AI 教育復興」的標誌性訊號。

2. **[tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)** — Python，3,073 ⭐/wk，23.1K 總 ⭐，**在榜第 2 日，▲ +178.4% 日增**。Local-first code intelligence graph for MCP and CLI。繼昨日（1,103 ⭐/wk）暴增後今日再翻倍——Agent 對 codebase 的理解方式正從「暴力檢索」轉向「知識圖譜化」，這個 repo 是該浪潮的旗艦。動能極猛，需觀察能否維持。

3. **[Dicklesworthstone/destructive_command_guard](https://github.com/Dicklesworthstone/destructive_command_guard)** — Rust，1,410 ⭐/wk，5.2K 總 ⭐，**歷史首次進榜**。專門阻擋 Agent 執行危險 git/shell 指令。Agent 安全性從「研究課題」正式落地為「實際工程需求」。對於任何在 production 跑 Agent 的團隊，這是剛需工具——不追踪它，下一個刪除生產資料庫的就是你的 Agent。

4. **[Nutlope/hallmark](https://github.com/Nutlope/hallmark)** — CSS，9,173 ⭐/wk，14.2K 總 ⭐，**連續 7 日在榜**。動能從「爆發期」進入「穩定期」，但仍是全榜絕對星數第二高。反 AI 垃圾美感已從主張變為剛需——當使用者開始用「hallmark 過沒」當作設計品的通过標準，它就不再只是一個 repo，而是一個 brand。

5. **[HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor)** — Python，2,754 ⭐/wk，28.4K 總 ⭐，**在榜第 5 日，▲ +16.0% 日增**。一邊是 [HKUDS/Vibe-Trading](https://github.com/HKUDS/Vibe-Trading) 交易 Agent 連日重挫（▼ -16.1%），一邊是 DeepTutor 教育 Agent 逆勢走強——Agent 在「學習」場域的剛需顯著高於「交易」。教育不涉及真金白銀，使用者的使用摩擦與心理阻力更低，反而可能跑得更遠。
