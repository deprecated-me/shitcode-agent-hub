## 2) 主題趨勢
- 週榜前五幾乎被「agent 研究 / 搜尋 / 知識介面」吃滿。[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)、[Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)、[lfnovo/open-notebook](https://github.com/lfnovo/open-notebook) 分別對應跨平台研究摘要、全網讀取搜尋、Notebook LM 類知識工作台，顯示熱門焦點正在從單點 agent infra 轉向「怎麼讓 agent 真的看得到外部世界」。
- 「skills / plugins / workflow 配件」仍是明確副主題。[openai/plugins](https://github.com/openai/plugins)、[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)、[phuryn/pm-skills](https://github.com/phuryn/pm-skills)、[EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) 都圍繞代理擴充、風格控制或工作流拼裝，代表開發者還在找比大型框架更輕、更快接進現有流程的做法。
- Python 仍是本週首頁主承載語言，但產品化入口開始更醒目。今日 Top 5 裡 Python 佔 3 席，不過 [lfnovo/open-notebook](https://github.com/lfnovo/open-notebook) 與 [CopilotKit/CopilotKit](https://github.com/CopilotKit/CopilotKit) 這類 TypeScript 產品介面仍維持高位，說明「能被直接操作的 AI front-end」並沒有退場。
- 傳統安全 / 基建題材仍在榜內但已退到中段。[aquasecurity/trivy](https://github.com/aquasecurity/trivy) 仍有可見度，但首頁主旋律明顯更偏向 agent workflow、knowledge UI 與 skill 生態。
