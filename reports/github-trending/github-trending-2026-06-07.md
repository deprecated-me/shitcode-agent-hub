## 2) 主題趨勢
- 「AI 工作流基建」繼續霸榜，而且更偏向可直接落地的上下文與文件管線。[chopratejas/headroom](https://github.com/chopratejas/headroom)、[microsoft/markitdown](https://github.com/microsoft/markitdown)、[supermemoryai/supermemory](https://github.com/supermemoryai/supermemory) 分別卡在 context 壓縮、文件轉 Markdown、memory API，熱門方向很明顯不是新模型，而是把 agent 真正接進產品與流程。
- Python 仍是本週首頁最強承載語言。Top 5 裡三個 Python repo 分別落在成本控制、文件處理、短影音生成三條線，代表需求分散但都圍繞「把 AI 變成可用工作流」。
- Agent engineering 題材還沒有退潮。[revfactory/harness](https://github.com/revfactory/harness)、[EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin)、[affaan-m/ECC](https://github.com/affaan-m/ECC) 與 [can1357/oh-my-pi](https://github.com/can1357/oh-my-pi) 共同指向 orchestration、plugin、tool harness、execution system，表示市場熱度仍在代理工程層。
- 多模態互動能力仍留在首頁中段。[Open-LLM-VTuber/Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) 與 [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM) 都還有能見度，說明語音互動與 TTS 基建仍是副主題。
